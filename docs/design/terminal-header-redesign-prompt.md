### Головна структурна різниця

Зараз `AccountBar` — окремий рядок **над** `TerminalHeader`, а метрики — це `<dl>` без карток.
У референсі **все всередині однієї великої картки** із заокругленими кутами: рядок акаунта,
рядок символу і три зони метрик розділені тонкими лініями.

Це не косметика — це зміна структури. Не намагайся досягти вигляду лише класами на поточному DOM.

| Фон сторінки | `#0A101E` → `#0B1121` | градієнт зверху вниз |

| Основний синій | `#307DFD` | ask, equity, прогрес-бар, кнопка |

| Червоний | `#E14C55` | bid, 24H, бейдж BREACHED |

| Приглушений текст | `#8FA3C4` | підписи, email, дата |
| Білий текст | `#F4F7FF` | значення |

### Мапінг на наявні токени

```
--primary: #4388ff   ← близько до #307DFD, але не те саме
--danger:  #f43f5e   ← рожевіший за #E14C55
--highlight: #55d6e8 ← близько до #30C8F1
--border:  #223052
--radius:  0.625rem  (10px)
```

**Рішення:** глобальні токени не чіпаємо. Для розбіжностей використовуй локальні
arbitrary-значення Tailwind (`bg-[#307DFD]`, `text-[#E14C55]`) або scoped CSS-клас
у `globals.css` з префіксом `.terminal-*`. Зеленого токена немає — або arbitrary-значення,
або новий scoped `--terminal-live`. Обране рішення зафіксуй у звіті.

## СПЕЦИФІКАЦІЯ ПО ЗОНАХ

Розміри шрифтів — стартові значення. Підганяй, порівнюючи з референсом; важлива
візуальна вага, а не формальна відповідність.

### Зона 1 — рядок акаунта

- Висота 56px, горизонтальні відступи 24px, нижня межа `1px rgba(255,255,255,.06)`.
- Ліворуч: підпис **Account** — 13px/600, колір `#307DFD`.
- Далі `<select>` у вигляді пілюлі: висота 38px, `rounded-full`, межа
  `1px rgba(255,255,255,.08)`, фон `#0B1224`, padding `0 16px`.
  Вміст: `displayId` (14px/600, білий) + `·` (приглушений) + статус у нижньому регістрі
  (14px/400, `#8FA3C4`). Шеврон 16px праворуч.
  **Важливо:** залиш нативний `<select>` (a11y + наявний `onChange`), стилізуй через
  `appearance-none` і наклади шеврон абсолютом. Не замінюй на `DropdownMenu` —
  це змінить поведінку.
- Праворуч: email (13px, `#8FA3C4`), відступ 16px, кнопка **+ New Challenge**
  (висота 38px, `rounded-full`, `linear-gradient(90deg,#307DFD,#30C8F1)`,
  білий текст 14px/600, іконка `Plus` 16px), відступ 12px,
  **Sign out** (ghost: `LogOut` 16px + текст 14px/500 білий).

### Зона 3 — картки метрик

Спільна «оболонка» картки: `rounded-2xl`, межа `1px rgba(255,255,255,.08)`,
фон `#080E1C`, padding 20px 24px, `overflow-hidden`.

**Картка A — EQUITY (42%)**
- Заголовок: іконка терезів 16px кольору `#307DFD` + `EQUITY` 11px uppercase tracking .1em `#8FA3C4`.
- Значення: **40px/1.1, font-semibold, `#307DFD`, `tabular-nums`**.
- Горизонтальний роздільник `1px rgba(255,255,255,.07)`, відступ зверху 16px.
- Під ним **дві колонки в ряд**: `BALANCE` │ `FREE MARGIN`, розділені вертикальною лінією.

  **Це зміна:** зараз вони стоять один під одним (`TerminalHeader.tsx:96-99`).
- Декоративне світіння планети в правій частині: **тільки CSS** — `radial-gradient`
  з центром за межами картки, `opacity ≤ .5`, обов'язково `pointer-events-none`
  і не поверх тексту. Якщо в `public/` вже є відповідний ассет — використай його
  і вкажи шлях у звіті; нових зображень не додавай.

**Картка B — MARGIN (11.5%)**
- Та сама оболонка. Іконка стовпчиків 16px `#307DFD` + `MARGIN` 11px uppercase.
- Значення 22px/600 білий.

**Картка C — DAILY DD BUFFER (решта)**
- Та сама оболонка.
- Заголовний рядок: іконка + `DAILY DD BUFFER` ліворуч; значення 16px/700 білий
  притиснуте праворуч; `0% USED` 11px uppercase `#8FA3C4` ще правіше.
- Прогрес: висота **10px**, `rounded-full`, трек `#101A2E`, заливка `#307DFD`.
- **Логіку збережи:** ширина = залишок буфера, кольори за наявними порогами
  (`>=0.8` → danger, `>=0.5` → warning) — `TerminalHeader.tsx:121-136`.
