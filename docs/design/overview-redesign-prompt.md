### Зона 7 — Фон

`space-background.tsx` рендериться на 7 сторінках, тому **не змінюй поточний вигляд**.
Додай проп з дефолтом:

```tsx
export function SpaceBackground({ variant = 'grid' }: { variant?: 'grid' | 'planet' })
```

`variant="planet"` (тільки Overview):

1. База: `linear-gradient(180deg,#05080F 0%,#08101F 55%,#060B16 100%)`.
2. Планета — велике коло, зсунуте за правий нижній кут, **тільки CSS**:

```
position: absolute; right: -22%; bottom: -68%; width: 1150px; aspect-ratio: 1;
border-radius: 50%;
background: radial-gradient(circle at 50% 50%,
  #07101E 0 62%, #0C1B31 70%, #1B4570 76%,
  #3E86C8 79.5%, #9BD4FF 81%, rgba(90,150,220,.45) 82%, transparent 86%);
box-shadow: 0 0 180px 40px rgba(70,140,220,.18);
```

3. Зорі — 1–2px крапки через `radial-gradient` на прозорому шарі, `opacity:.45`,
   лише у правій половині, щоб не рябіло під текстом.
4. Усе — `aria-hidden`, `pointer-events-none`, `z-0`; контент уже має `z-10`.
5. Жодних анімацій. Нових зображень у `public/` не додавай.

Поточні cyan/orange-світіння й сітку для `variant="planet"` прибери — на референсі їх немає.

## ПРИВ'ЯЗКА ДАНИХ (не хардкодь жодного числа)

| Елемент | Джерело |
|---|---|
| EQUITY | `selected.equity` |
| PROFIT / PNL | `selected.todayPnl` |
| TOTAL PNL | `selected.totalPnl` |
| STATUS | `phaseLabel(selected)` + `selected.isBreached` |
| Чіп акаунта | `selected.primaryLabel` + `phaseLabel(selected)` |
| Графік | `data.curves[selected.id]` |
| Risk: денний | `selected.dailyDrawdownPct` / `selected.dailyLossLimitPct` |
| Risk: trailing DD | `selected.maxDrawdownPct` / `selected.maxDdLimitPct` |
| Рядки списку | `data.accounts` |
| Бар рядка | `account.profitProgress` (0…1), `null` → 0 і `—` |
| Відсоток рядка | `Math.round(account.profitProgress * 100)` |

**Одна правка логіки дозволена:** `phaseLabel()` зараз не знає про `PASSED` і поверне
`PHASE 1` для пройденого челенджу. Додай гілку за `account.status`
(`PASSED`/`PASSED_PHASE_1`/`PASSED_PHASE_2` → `PASSED`, `EXPIRED` → `EXPIRED`)
перед перевіркою `phase`. Це display-only, бізнес-логіку не чіпає — зафіксуй у звіті.

## РОЗБІЖНОСТІ В МАКЕТІ — НЕ ВІДТВОРЮВАТИ

Макет містить помилки. Не копіюй їх:

1. **Зайва `9` у першому рядку** (`$2,942.07 / 9  $10K`). Рендер має бути
   `$2,942.07 / $10K` у колонці значення і `9%` у колонці відсотка.
2. **`PASSED` пофарбований червоним.** Це успіх — роби зеленим (`#22D39B`).
   Якщо хочеш строго 1:1 — це один рядок у мапі тонів, але семантика важливіша.
3. **Бар першого рядка синій, хоча акаунт `BREACHED`.** Колір бару визначається даними
   (`isBreached` → червоний), а не скріншотом.
4. **`(Demo)` у чіпі.** У нас там фаза акаунта — лишай `phaseLabel(selected)`.
5. **Значення й відсоток наїжджають на бар** у першому рядку. Використовуй колонкову
   сітку, а не абсолютні відступи.
6. **Числа в макеті — живі дані** ($2,956 / +$0.00 / −$44.00). Вони збігаються з поточним
   скріншотом, тобто це той самий акаунт у новій шкірі. Нічого не вписуй руками.
